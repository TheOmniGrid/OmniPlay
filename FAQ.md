# Frequently asked questions

## What is OmniPlay?

OmniPlay is a Windows game-library manager based on Playnite, with per-game ReShade, Special K, and DXVK management built into the product.

## Does it replace or modify Playnite?

No. OmniPlay uses its own program and data directories. It does not read or write Playnite's data folder. See [Compatibility with Playnite](README.md#compatibility-with-playnite).

## Is there a public download?

Not yet. The public repository is a product and documentation home, not a binary distribution channel.

## Does it collect telemetry?

No OmniPlay telemetry, usage reporting, account, or crash-upload service is included. Optional third-party catalogue and price integrations use keys supplied by the user. See [PRIVACY.md](PRIVACY.md).

## What are the requirements?

Windows 10 or Windows 11, 64-bit. The required .NET runtime ships with the application.

## Where should problems be reported?

Use [SUPPORT.md](SUPPORT.md). Security reports belong in private email as described in [SECURITY.md](SECURITY.md).
